# Popup Themes

Copy any file to `popup.css` beside `chibipop.exe`.
Restart chibipop, or click **Save & Apply** in the CSS editor.

| Theme | Base | Look |
|---|---|---|
| `midnight-purple.css` | dark | Deep violet, bold headwords, italic readings. |
| `warm-paper.css` | dark | Cream on brown, Yu Mincho. Aged-paper feel. |
| `ocean-breeze.css` | dark | Cool blue-green on deep navy. |
| `sakura-light.css` | light | Clean white with pink accents. |

Set the matching base theme (`dark` or `light`) in `chibipop.toml`
before applying. A dark CSS on a light base will look wrong.
